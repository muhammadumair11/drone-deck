- Drone Deck: Guided setup now works on a PC with no WSL. A new Ubuntu has only root, so the wizard holds at the Linux environment step until a Linux user exists, and "Initialize Linux user" opens a window that creates the account (the password is typed into Linux's own prompt, never into Drone Deck) and makes it the default user; setup rescans on its own when a WSL or distribution job finishes and while it waits for that account. A step that is quiet for five minutes while still working, such as the Ubuntu download, now says "Still working" instead of "Needs attention", and the installer package no longer carries the Windows setup test fixture.
