I've been building Drone Deck: a Windows desktop workspace for learning and developing autonomous drone systems.

The project grew out of my experience setting up PX4, simulators, QGroundControl and Python tools, then trying to understand how they fit together.

Drone Deck brings tool preparation, simulator sessions, telemetry, ROS 2 recordings, model access and inference workflows into one workspace. It's built in Rust with the Rune UI framework, with Linux tooling running through WSL 2.

I'm opening the source and welcoming contributors. This is an early preview: some integrations still need testing on fresh Windows installations and real hardware. The remaining limitations are documented in the repository.

I'd welcome help with Windows/WSL setup testing, PX4 and Gazebo integration, ROS 2 workflows, usability, documentation and reproducible bug reports.

Development has been AI-assisted, with iterative code review and automated testing. I'm sharing both the software and what I'm learning as I build it.

Repository: https://github.com/muhammadumair11/drone-deck
