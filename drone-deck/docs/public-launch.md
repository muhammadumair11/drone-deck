# Public preview launch

Drone Deck 0.9.2 is an early preview for Windows and WSL 2. Local evidence: formatting and 375 Rust tests passed; installer and zip compiled; packaged executable completed a headless preview. Remaining limitations are tracked in Known issues. The installer is unsigned.

## Publication steps

1. Complete the approved history cleanup and push the prepared source.
2. Change repository visibility in GitHub Settings when ready. Review the promotional video for personal paths, tokens and location data.
3. Enable Issues and private vulnerability reporting when available.
4. Tag the prepared commit v0.9.2 and push that tag. The workflow runs Windows and Linux checks and prepares a **draft** preview release with installer and zip.
5. Review the draft and its assets, retain the pre-release designation, and publish.
6. Publish the LinkedIn draft after public repository and download links work.

Visibility changes, release publication and posting remain maintainer actions. No code-signing service has been configured.
