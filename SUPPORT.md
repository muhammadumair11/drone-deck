# Support

Start with the [user guide](drone-deck/docs/user-guide.md), [troubleshooting](drone-deck/docs/troubleshooting.md) and [known issues](drone-deck/docs/known-issues.md).

Use GitHub Issues for reproducible bugs and feature requests. This is a community preview with no commercial support or response-time guarantee. General tool questions may need the respective PX4, ArduPilot, Gazebo, ROS 2 or QGroundControl support channels.

Initial environment: Windows 10/11 x64, WSL 2 and Ubuntu 24.04. Alternative distributions, clean-machine automatic installation, ROS 2 end-to-end operation and physical controllers have validation gaps.

The executable and installer are unsigned. Downloads may trigger Windows reputation warnings. Verify the repository and release source, and use a simulator for initial evaluation.
